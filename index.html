About the Project

This application is a real-time chat platform where users can log in to send public and private messages seamlessly. It is designed for teams, communities, and groups who need organized communication, with features like group chats, read receipts, and live typing indicators. Admin users have additional controls to create and manage group chats, as well as add or remove members, ensuring structured and secure collaboration.
